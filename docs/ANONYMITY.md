# Anonymous review distribution

This archive omits the manuscript authors' names, contact addresses and
institution from its own source metadata and documentation. Built Python
distributions are checked separately; editing only a README is insufficient.
Third-party dataset citations, source URLs and copyright notices are retained.

For review, provide the ZIP as an anonymous attachment or through an anonymous
download location. A named hosting account, commit history or package-index
owner can reveal identity even when these files do not. No repository or
package-index publication is performed by this release.

The anonymous copyright presentation does not change ownership or grant a new
open-source license. The original paper and scientific reference records stay
frozen. This file describes archive contents, not an assurance that an external
hosting account or all public cross-references are anonymous.
